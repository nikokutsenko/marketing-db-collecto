## Технічно недосяжно з цього середовища (не намагатись повторно)

Перевірено емпірично 2026-07-11: мережевий шлюз цього середовища блокує
пряме з'єднання (curl/playwright/WebFetch) з усіма хостами, крім
`*.googleapis.com` і кількох пакетних реєстрів (npm/pypi/github). Це
блокування відбувається **до** будь-якої автентифікації — тобто API-ключі
чи токени для нижченаведених сервісів не допоможуть з цього середовища:

- Reddit (www./old., офіційний API через oauth.reddit.com) — CONNECT
  tunnel 403 на рівні шлюзу незалежно від credentials
- Meta Graph API / Ad Library API (graph.facebook.com) — так само
- TikTok Creative Center / TikTok API — так само
- Instagram — так само

**Єдиний спосіб отримати дані з цих платформ** — користувач вручну
експортує (скріни, збережений HTML, CSV) і передає файлом/текстом;
тоді я структурую. Якщо це знадобиться — попросити окремо, не чекати
що автоматичний цикл сам туди дотягнеться.
