# Terratonic — Research Database

Дослідницька база для маркетингової команди бренду **Terratonic** (БАД:
вітграс, вітгерм, Україна).

- `research/STATUS.md` — поточний стан, обмеження джерел, лог прогресу.
- `research/BACKLOG.md` — черга завдань для автономного циклу збору.
- `research/psychographics/` — Частина 1: психографічна база аудиторії
  (страхи, болі, заперечення, бажання, цілі — з цитатами й посиланнями).
- `research/creatives/` — Частина 2: бібліотека сильних креативів
  конкурентів (з урахуванням обмежень, див. `creatives/LIMITATIONS.md`).

## Бренд-обмеження (діють на всю базу)

- Не зберігати UGC, контент з обличчями, "до/після" — навіть як приклад
  креативу, навіть якщо він популярний у конкурентів.
- Аудиторія українська — пріоритет українським/локальним джерелам.
- Тільки структуровані дані. Без фінального копірайту чи відповідей клієнтам.
